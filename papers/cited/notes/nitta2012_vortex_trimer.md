# nitta2012_vortex_trimer — resolves SSV-I D2

**M. Eto & M. Nitta**, *Vortex trimer in three-component Bose-Einstein
condensates*, Phys. Rev. A **85**, 053645 (2012), arXiv:1201.0343.

New reference, introduced by the audit to settle what a three-vortex junction
actually requires.

## Abstract

> Vortex trimer is predicted in three-component Bose-Einstein condensates
> (BEC's) with **internal coherent couplings**. The molecule is made by three
> constituent vortices which are **bounded by domain walls of the relative
> phases**.

## Structure, §I

> In the case of multiple hyperfine spin states, the internal coherent coupling
> between multiple components can be introduced by Rabi oscillations. … A
> sine-Gordon domain wall … with the total configuration being a molecule of two
> constituent vortices, namely, a vortex dimer.

Two components → vortex **dimer**; three components → vortex **trimer**.

## Consequence for SSV

A relative phase — and therefore a domain wall to bind the constituents —
requires **more than one component to exist at all**. In a single-component
U(1) condensate the order parameter is single-valued, so circulation is
quantized and conserved and any node requires Σᵢnᵢ = 0. Three unit filaments
oriented into a node give 3 ≠ 0: **forbidden**. The only admissible three-way
node is a branching n=2 → 1+1, and doubly-quantized vortices are dynamically
unstable to splitting in a repulsive condensate.

**Bare SSV has no stable symmetric Y-junction.** This is the same structural
deficiency recorded in #178 (π₃(S¹) = 0 ⇒ no fermionic solitons), with the same
indicated repair: a multi-component condensate.
