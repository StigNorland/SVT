# Accessible source transcriptions

This directory contains tracked Markdown transcriptions of audit-relevant pages
that cannot be extracted reliably from the available source file, especially
owner-supplied or image-only scans.

Each transcript must record:

- source identity and stable identifier;
- how the page images were obtained and when;
- page or section boundaries in reading order;
- prose and equations without silent correction;
- `[illegible]`, `[uncertain: ...]`, or an explicit editorial note wherever the
  image cannot be read confidently;
- the corresponding citation-evidence note in `papers/cited/notes/`.

Transcribe the complete supplied paragraph and any governing context needed to
interpret it. For equations, include the prose that introduces and explains
them. Preserve page numbers so a reader with the scan can compare line by line.

Do not turn this into a shadow library: transcribe only the audit-relevant
material unless the source's licence permits broader redistribution.
