# H-SSV-VI — Cross-Scale Integration

**Status:** planned; synthesis and decision paper.

## Scope

Confront the surviving H-SSV model across scales and decide its relationship to
the existing SSV programme:

- define the measurable correlation condition for shared galaxy/cluster screen
  modes;
- predict relaxed-cluster and merging-cluster dynamics and lensing;
- test composition of global and effective subsystem screen modes without
  information or gravity double-counting;
- compare local, galactic, cluster and cosmological parameter consistency;
- audit every dependency on SSV Papers III and IV;
- determine whether H-SSV remains independent, supplies Paper IV's missing
  upstream source, requires revisions to Papers III/IV, or is falsified.

## Exit gate

One parameter-consistent theory must survive independent local-gravity,
galaxy, lensing, cluster and cosmological tests. Any incompatibility is reported
as a negative result rather than repaired by scale-specific laws.

## Excluded from this paper

No integration with the SSV papers merely because the vocabularies are
compatible. Integration requires passed derivation and observation gates.
